Табель-коды

Ручные отметки табеля (отпуск, больничный, командировка и т.п.) сразу для всех сотрудников — одна таблица вместо карточки по каждому человеку. Эти коды перекрывают автоматический расчёт по сканам и коды из планового графика; там, где ничего не проставлено — код подставляется из графика («📅 Графики») или считается по факту прихода/ухода при экспорте табеля. Выберите код слева, затем кликайте по дням в таблице.
